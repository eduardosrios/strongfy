# Security Policy

## Supported Versions

Strongfy has not published its first release. Security support will apply to the latest maintained release once versions become available.

| Version | Supported |
| --- | --- |
| Unreleased development | Yes |
| Older or archived versions | No |

## Reporting a Vulnerability

Do not disclose suspected vulnerabilities in public issues, pull requests, discussions, or social media.

Report vulnerabilities privately to `wpublish@gmail.com` with:

- A concise description of the issue
- Affected files, pages, or versions
- Reproduction steps or a proof of concept
- Potential impact
- Any suggested mitigation

Reports will be acknowledged when practical, evaluated according to severity and reproducibility, and handled with reasonable confidentiality. Please allow time for investigation and remediation before any public disclosure.

## Safe Harbor

This policy does not grant permission to access data, systems, or accounts you do not own; disrupt services; perform destructive testing; violate privacy; or act outside applicable law. Research must remain limited to the publicly available Strongfy project and your own test environment.
