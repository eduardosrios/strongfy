# Contributing to Strongfy

Thank you for your interest in Strongfy.

## Before Contributing

Strongfy is proprietary software. Public access to the repository does not grant permission to use, copy, modify, distribute, commercialize, or create derivative works from its contents.

Contributions are accepted only when authorized by the project owner. Before starting work, open an issue describing the proposed change and wait for written approval.

## Contribution Process

1. Open a focused issue describing the problem, proposed solution, and expected user impact.
2. Wait for maintainer approval before implementing the change.
3. Create a narrowly scoped branch.
4. Follow the existing HTML, CSS, and vanilla JavaScript conventions.
5. Test responsive behavior, accessibility, browser compatibility, and interactive states.
6. Submit a pull request with a clear summary, screenshots for visual changes, and test notes.
7. Address review feedback without adding unrelated changes.

## Content and Asset Requirements

- Submit only assets you created, own, or have explicit permission to contribute.
- Document the source and license of third-party assets.
- Do not include confidential information, credentials, generated build artifacts, development notes, or unrelated files.
- Use English for source code, documentation, interface copy, commit messages, and pull request descriptions.

## Rights and Licensing

Submitting material does not change the proprietary status of Strongfy. A contribution may require a separate written agreement before acceptance. Unless the project owner confirms acceptance in writing, no submission grants either party additional rights beyond those provided by applicable law and GitHub's Terms of Service.

## Conduct

All participation must follow the [Code of Conduct](CODE_OF_CONDUCT.md).
